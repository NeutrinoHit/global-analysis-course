# Глобальный анализ данных в физике

Курс DN о совместной интерпретации физических данных. Русская и английская
версии слайдов и книги готовятся. Программа включает 16 лекций, шесть
вычислительных практикумов и итоговый проект; основа — курс по статистическому
анализу данных.

## Структура

- `course.yml` — порядок и названия 16 тем на двух языках.
- `ru/`, `en/` — главные страницы языковых версий.
- `<lang>/slides/planned/` — пустышки лекций: только метаданные, без содержания.
- `<lang>/slides/assets/` — предметные рисунки и код лекций.
- `<lang>/book/planned/` — соответствующие пустышки глав.
- `<lang>/book/chapters/` — будущие готовые главы.
- `shared/` — общие компоненты, код, ноутбуки и настройки PDF.
- `_extensions/neutrinohit-media/`, `media.lock.json` — вставка общих медиа.

Готовых лекций и глав пока нет. `planned/` исключён из рендера и ресурсов.
Для публикации готовая лекция переносится в `slides/` с номером `NN_`, а глава —
в `book/chapters/` с тем же номером; затем они явно добавляются в конфигурации.
Русские и английские материалы готовятся и проверяются независимо.

## Сборка

```bash
make help
make site
make ru-html
make en-html
```

На Mac из рабочего пространства NeutrinoHit:

```bash
make site QUARTO=../quarto-neutrinohit
```

`make site` публикует в `_site/` главные страницы и индексы слайдов RU/EN.
Книги пока не публикуются: отдельные цели `ru-html`, `en-html`, `ru-pdf`,
`en-pdf`, `ru-epub`, `en-epub` сохраняют их в `_book/<lang>/`.
Для PDF нужны LuaLaTeX, Libertinus и пакеты из `scripts/setup_book_tex.sh`.
Сайт не требует TeX или соседних репозиториев; CI использует общий workflow NH.

Главные страницы и индексы `index.qmd` сохраняются в Git. Их источник —
`course.yml` и `scripts/build_course_pages.py`; после изменения программы
выполняется `make pages`, ручные изменения этих страниц не сохраняются.

## Общий дизайн

Канонические компоненты находятся в `neutrinohit-map/assets/{site,reveal,books}`.
В курсе хранятся локальные копии для независимой сборки. Обновление выполняется
явно, через штатные скрипты синхронизации и общий механизм проверки изменений:

```bash
make check-shared
make sync-shared
```

Эти две операции требуют соседний `neutrinohit-map`; обычная сборка — нет.
Локальные изменения общих файлов не перезаписываются синхронизацией.
RevealJS: 1600×1000, тема `black` и `neutrinohit-reveal.scss`; общие параметры
макета собраны в `<lang>/slides/_metadata.yml`. Формат по умолчанию, тема и футер
слайдов заданы в `<lang>/slides/_quarto.yml`; HTML-индекс явно выбирает свой
формат и тему. Обычные `quarto render` и `quarto preview` не требуют `--to`.
Предметные стили, код и рисунки
размещаются в `assets/<lecture-slug>/`, содержание лекции — в её `.qmd`.

## Анимации и данные

Фильмы, документы и крупные наборы данных хранятся в GitHub Releases проекта
[media-global-analysis](https://github.com/NeutrinoHit/media-global-analysis).
Видеофайлы в репозиторий курса не добавляются. Регистрация и выпуск идут через
общий каталог NH и `nh_media.py`; версии закрепляются в `media.lock.json`.

После публикации и проверки медиа используются `nh-video` и `nh-url`:

```text
{{< nh-video <id> variant="film-ru" controls=true >}}
{{< nh-url <id> variant="data" >}}
```

Вызовы приведены как схема: медиа курса пока нет. Полная процедура —
[правила медиатеки NH](https://github.com/NeutrinoHit/NeutrinoHit.github.io/blob/main/docs/media-library.md).
Для книжного PDF у каждого будущего фильма должен быть статический постер.
